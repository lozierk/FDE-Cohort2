This is the run that changed where run logs go. The search worked, the model turn behind it threw, and the loop ended the run as an error with the search's eight tenths of a cent still on the bill. What I learned was not about the error but about placement: this log first landed in runs/ next to the successes, where rule A2 would have read an honest failure as a dishonest success. Error runs now go to runs/failing/ at write time, by construction. I kept this one because a failing trajectory the grader can read is worth more than a clean folder.
